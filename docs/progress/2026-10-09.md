## Work streams

### 1. SoundCloud import and vertical video generation

Built a Node/npm application with a React editor, Express API, and serial background job queue. Public SoundCloud audio and cover artwork import through yt-dlp; artist metadata and actual decoded audio drive the portrait composition. A real SoundCloud import verified audio, artwork, and attribution. Output is 1080 × 1920 H.264/AAC at 30 fps, with clip selection, spectrum, waveform, palettes, preview, cancellation, and persisted exports.

### 2. Local lyric transcription and captions

Integrated Transformers.js and a local timestamped Whisper model, with no paid API key or audio upload. Automatic word timing feeds animated phrase captions with current-word highlighting; the editor permits text and timing corrections and instrumental mode. An original vocal fixture mixed over music passed transcription and export through the HTTP API, recognizing 17 timed words. Cancellation preserved the source media. Automatic lyric accuracy remains dependent on the recording and must be reviewed.

### 3. Original logo, intro/outro, and post description

Created the original discovery-pulse logo as SVG and transparent PNG, with shared Canvas animation code. Music plays for 2.5 seconds before the intro logo appears; the same reveal reverses on exit and is reused in a 3.2-second silent outro after the clip. A three-second black thank-you card follows. Every export includes the artist, artwork, generated description, and downloadable SRT; the editor can copy the description and download cover art.

### 4. Verification and documentation

Added 27 tests spanning audio analysis, input validation, caption timing, branding timeline, queue serialization, cancellation, and restart recovery. A 14.2-second full-HD export verified eight seconds of selected music followed by 6.2 seconds of ending; source/output audio correlation was 0.99998 and the outro was silent. Decoded frames and desktop/mobile screenshots were visually reviewed. Added setup documentation, model-cache guidance, the consolidated checklist, and GitHub Actions for tests, build, and an actual render.
